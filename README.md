# Crest

This small project is a attempt of creating a vectorized crest for my family.

The image basically consists in a hen's feather crossed with a leaf from a _[Ceiba speciosa][1]_.
The hen represents the unity and protection within the family, on how the mother hen protects its
children. The tree represents our roots, for us never to forget where we are from and who we are.
