# Crest

This small project is a attempt of creating a vectorized crest for my family (me and my wife).

The image basically consists in three things:
1. In the upper section, a symbol we designed to represent our ideals
2. In the lower-left section, a flower from a _[Ceiba speciosa][1]_
3. In the lower-right section, a flower from a _[Handroanthus heptaphyllus][2]_

(Obs: I used some poetic license while making the flowers)
